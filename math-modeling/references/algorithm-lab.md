# 可运行算法实验

[modeling_lab.py](../scripts/modeling_lab.py) 是本项目独立实现的教学例，不包含上游程序全文。用于验证核心数学结构和结果交接，不是生产求解器，也不替代赛题的数据分析。示例参数均为合成设定；唯一摘录论文表数的项目是 P25 的局部算术核验。

## 运行

以下命令从完整仓库根目录执行（tests随完整仓库分发；单独安装技能时可运行实验与证据检查入口）。在项目内创建独立环境，安装 NumPy、SciPy；生成图文报告还需 Matplotlib：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy scipy matplotlib
.venv/bin/python math-modeling/scripts/modeling_lab.py --out work/lab-result
.venv/bin/python math-modeling/scripts/check_evidence.py work/lab-result/evidence.json
.venv/bin/python -m unittest discover -s tests -v
```

脚本不联网。`--out`会创建目录并覆盖其中同名的演示结果文件，应使用独立输出目录。省略`--out`只打印JSON。已验证依赖版本保存在每次`results.json`，默认不强迫其他任务安装这些依赖；现有三个辅助检查/检索脚本仍只依赖标准库。数值测试未安装依赖会明确跳过，不能将跳过算作通过。

## 实验与独立标准

| 实验 | 验证什么 | 不证明什么 |
|---|---|---|
| AHP与TOPSIS | 已知一致权重恢复、拒绝非互反、成本/收益方向、常数指标与并列 | 偏好客观正确或某业务排名合理 |
| 主成分回归 | 零和主轴不丢失、训练内缩放、逆标准化、留出点预测 | 真实小样本数据上的泛化能力 |
| GM与移动平均 | 8个滚动原点；指数合成序列上同期限比较；常数序列极限 | GM对任意短数据都优于其他方法 |
| LP/MILP | 同一资源模型松弛上界、整数枚举对照、约束残差 | 大规模模型或启发式最优性 |
| Floyd与最大流 | 负边/零边/不可达/负环；反向增广与最小割证书 | 所有图模型、费用流、下界流均已实现 |
| 模拟退火TSP | 5种子、相同预算、全枚举小例、完整回路、best轨迹单调 | 任意规模均能找到最优 |
| 周期交通CA | 单车一步推进；8元胞全部256状态的占位与车数守恒 | 实际换道、路口或交通流已标定 |
| 热方程 | 正弦初值解析解、显式差分稳定步长、空间加密误差约四倍收敛 | 多层织物、复杂边界的完整复现 |
| 半管滑道 | 无摩擦能量守恒、停滑事件、容差收紧、不同底部长度 | P26整题、主动蹬伸/旋转最优设计 |
| P25原表算术 | 以表8重算两比值，核对原文不等号 | 恢复其仿真数据或验证悖论理论条件 |

## 完整微型交付链

半管例从固定合成参数出发，定义状态q=v²与弧长s，向上为y正向，满足

`dq/ds = -2g y′(s) - 2μ[g x′(s) + κ(s)q]`。

两段四分之一圆弧和中间直线分别积分，避免跨曲率跳变不加处理；q到0即停止，禁止sqrt负数后伪造出口速度。无摩擦时入出口等高，应恢复入场速度。μ不含质量时质量消去。半径固定的三个底部长方案同时改变总宽度与总弧长，因此结论只能用于本例比较。

执行后生成 `results.json → halfpipe.csv → halfpipe.png/.svg → manuscript.md → evidence.json`。图和表全部来自本次求解，数值台账绑定结果文件SHA-256及JSON字段。已生成可查看的[演示交付](../assets/lab-example/manuscript.md)。改变代码或参数必须重跑，不从旧图复制新结论。文稿为Markdown演示，不宣称已编译赛事论文PDF。
