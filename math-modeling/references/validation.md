# 验证与可复现求解

## 分开四类误差

| 证据 | 回答的问题 | 不能证明什么 |
| --- | --- | --- |
| 拟合残差 | 模型能否解释用于估计的数据 | 样本外预测、因果效应 |
| 留出/滚动误差 | 对未用于拟合的记录是否有效 | 结构变化后的长期有效性 |
| 网格、容差与算法误差 | 数值计算是否接近所定义的数学问题 | 数学模型是否反映真实系统 |
| 仿真统计区间 | 给定机制和输入分布下结果有多不确定 | 机制或输入分布本身正确 |

按题目选择必要证据，避免一律堆砌检验。R01、R03、R04、R06 与 R07 对应的历史要求见案例库。

## 数据与运行契约

保存足以复算关键结果的信息：输入文件及哈希、来源、字段单位、清洗规则、数据划分、模型参数、随机种子、依赖版本、运行命令与输出文件。可以是简短 Markdown 加 JSON 配置，不强制复杂工程框架。

先检查以下不变量，再调模型：

- 时间戳、单位及空间坐标含义一致；经纬度转距离使用合适的球面或投影计算。
- 业务键唯一；多表连接前后记录数合理；同一主体不因重复同时进入训练与测试。
- 真实零与缺失分开，负数、常量列、无穷值和空数组有处理；插补保留原始标记。
- 指标分子、分母来自同一范围，比例不被重复换算为百分数。
- 特征在决策时确实可用；历史完成情况可作标签，不能作新任务的已知属性。

真实数据缺失时，用合成样本验证算法和边界，标注“合成示例”。不能把其得分写成赛题成绩。

## 优化与调度

求解器返回后，从原始约束而非惩罚后的适应度检查：

1. 终止状态、可行解是否存在、变量域和整数容差。
2. 每条约束的残差及最大违反量；容量/时限等单位允许的容差。
3. 独立重算目标值、成本和硬约束。
4. 同一时间预算的基线；有有效上下界时再报告差距。
5. 固定方案的扰动性能与每个扰动场景重新优化的性能分开。

调度核查资源互斥、工序、加工最小时长、运输时间、位置连续、库存/携带容量、启动空载、故障报废、维修期禁用以及班次结束时未完成件。同时发生的上下料动作先确定真实资源占用语义，避免重复区间制造假冲突，或遗漏机械臂占用。

独立验证器读取导出的方案，不调用优化器的同一评分函数。`scripts/check_schedule.py` 检查通用资源区间、时长、释放时间、截止时间、优先关系与停机日历；详见 [数据契约与局限](schedule-checker.md)。它不能自动证明题意编码完整或调度最优。

最小反例优先：两任务争用同一资源；第二道工序先于第一道；维修中继续加工；计入下班后才完成的物料。不要仅验证最优值是否接近参考论文。

## 预测、评价与策略效果

预测按部署场景采用时间、空间或主体分组划分。在验证窗口中重做整个训练过程；报告朴素基线、误差尺度、区间覆盖。MAE/RMSE 按业务损失选择，零值附近避免直接使用 MAPE。分类按类别比例和代价检查混淆矩阵、召回、精确率与概率校准；阈值在验证集确定。

评价检查指标同向化、标准化、常数列和权重总和；做等权对照、权重/指标扰动及排名反转分析。说明谁的排名稳定、谁因偏好而变化，不以总分抹去利益冲突。

历史回归是关联，不自动揭示因果。定价后完成率的改变需要可支持的行为机制或实验；最大流分配在“会员完全接受平台调度”的假设下可行，不等于自主抢单一定实现。报告成本、覆盖范围、机会均衡和完成率，区分“发布价格总和”与“实际支付成本”。

两个方案成本不同时，同时给原始比较与同预算比较；不能把增加预算的收益全部归因于算法。P04 中 `62.1%→86.6%` 是 `+24.5` 个百分点、相对约 `+39.45%`。

## 机理与数值算法

- 检查量纲、初边值/交界面、守恒和参数物理范围；分别检查公式与代码。
- 用已知解析解、制造解、可计算的稳态极限或独立小规模求解验证实现。
- 减半网格/时间步长或收紧容差，观察目标变量和方案变化；稳定性不等于精度。
- 参数估计报告可辨识性、范围与相关性；同一测量曲线的拟合不是独立验证。将观测噪声传播到最终推荐方案。
- 传热阈值例：`∫1[Tskin(t)>44]dt≤300s` 表示超过阈值的累计时间。温度单调时用终止时刻减首次越界时刻；否则汇总所有越界区间。考虑时间步长与插值，不能把首次到达时刻当持续时间。
- CT 例：用已知模板正向投影，再标定与重建；核对坐标、角度正向、采样间距、增益、插值和矩阵尺寸。展示灰度的归一化不是物理吸收率标定。

## 随机仿真

写清随机量、分布、相关关系和种子。只给范围时，均匀分布是一种假设，需要与其他合理分布比较。

多次独立重复，报告样本数、均值、离散程度及适合的区间；重尾等待时间同时看高分位数和未完成任务。可使用共同随机场景降低策略差异估计的方差，但须按配对结果分析。逐时刻观测通常相关，不能当成大量独立重复来制造狭窄区间。

检查暖机、截尾和系统外等待。例如只统计成功通过收费站的车，会漏掉等待最久的车。有限班次中明确未完成件/未到达乘客的统计方式。

## 结果台账

每个重要结论记录题号、数值与单位、适用条件、产生它的命令/文件、验证证据、状态（已验证/模型预计/未验证）。写作时从台账取数。

表、图、摘要、结论和附件使用同一版本；对比指标由脚本重算。用合理有效数字，不将显示位数当测量精度。附件或环境不可得时，区分“已读方法”“静态检查”“已复算局部关系”和“已复现赛题结果”。
