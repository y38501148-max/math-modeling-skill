# 第三个仓库：从实际模板与绘图实现提炼规则

来源是固定提交83d8783的MathModelAgent。此前已读10个SKILL入口及相关规范/检查代码；本轮进一步读四个本科/MCM模板族的44个源文件、绘图入口和两份说明、三个具体绘图脚本，共50个文件。路径、Git blob和SHA-256见[实现来源台账](implementation-review.json)。本项目不复制分发这些文件；观察只适用于所读版本，未编译上游Typst/LaTeX模板。

## 采用、改写与避免

| 所读实现 | 有用设计 | 本技能的落地 |
|---|---|---|
| 中英文Typst/LaTeX分章节组织 | 把题目、模型、结果、验证与附录拆成可维护单元 | 沿用阶段接口，按真实题目组织章节，数字从计算产物导入 |
| zh/cumcm字体回退与zh/cumcm-latex字体检测 | 将中文/西文/代码字体分开处理 | 编译前检测已安装字体并记录替换，不承诺跨平台默认可用 |
| references独立文件 | 文献条目与正文结构可单独检查 | 使用真实参考记录和自动引用；核对标题不重复 |
| render_template.py的模板ID/别名映射 | 将用户图意图转成明确图型，输出PNG/SVG/PDF | 本技能按证据目的选图型，检查产物实际存在，再嵌入文档 |
| 复制到项目后再运行 | 项目修改不会直接污染共享模板 | 原创示例写独立输出目录，保留命令、版本、结果和图表 |

## 具体内容不能直接带入论文

四族章节样例包含相同的预填R²、RMSE改进、遗传算法参数和“鲁棒/最优”等结论；附录只展示一个读取data.csv的随机森林训练片段，无法证明前文全部模型、选择或优化结果。假设模板同时写可忽略交互，后文又引入交叉项，须按具体模型解决矛盾。将所有变量设为连续可微也不适合整数规划。使用任何样板前，把数值和结论改成待填证据项；只在有对应运行记录后写最终数值。

英文MCM两个主模板手写目录与total-pages=4；Typst页头还把物理页码减2，LaTeX另有不同分页逻辑。内容增长时这些静态数字会过期。需要自动目录/总页数或每次编译后对照实际页面，且根据当届要求决定摘要页、正文与附录如何计数。en/mcm-latex的references.tex还额外包含Sensitivity Analysis节，容易混入重复章节。赛事年份、队号、标题、日期都是需要核对的字段，不把模板发布日期当规则。

## 图形外观与统计量必须分开

本轮实际读取三个图脚本，未只依据图名判断：

- T057 `make_cv_roc_ci.py`：曲线由目标AUC与随机噪声生成，图例AUC来自常量，`p<0.01`直接写入字符串；带宽是折曲线均值±标准差，不是已计算的置信区间。迁移时必须输入真实逐样本标签/预测、外层测试或折外预测，重算ROC/AUC，明确置信区间的重采样单位与方法。没有检验过程就删除显著性标记。
- T058 `make_multiclass_shap_combo.py`：importance_table是预填数表，蜂群值由simulate_shap_values合成，未对模型调用SHAP解释器。迁移时必须绑定模型、解释样本、背景数据、类别顺序和输出尺度，核对加和关系；随机点只能标布局演示。
- T059 `make_rf_tpe_surface.py`：RMSE用解析曲面构造，试验点按预设区域抽样，插值后还混合解析真曲面；没有实际训练RF或运行TPE。迁移时输入真实超参数试验表，整数超参按整数域处理，标出实际采样点与插值范围，不用平滑曲面冒充已评估区域。

render_template.py在子进程返回0后打印预期路径，但不逐个检查文件；README也列预期名。执行成功、文件存在、数据真实和图有论证力是不同层次。本技能要求逐层核查，同时保留上游示例在布局表达上的参考价值。
