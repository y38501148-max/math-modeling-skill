# 算法选型与实现契约

本页来自两个资料仓库核心代码的成组审阅，并结合本科论文归纳。A101–A299 的固定版本与阅读/运行状态见 [算法审阅台账](algorithm-review.json)。197 个文件经过静态审阅；文件包含辅助函数、重复实现与教学代码，不代表197种算法。实际运行的上游程序仅 A196；其余风险是静态分析，不冒充 MATLAB 实验。原创数值例见 [算法实验](algorithm-lab.md)。

## 按数学结构选求解器

| 模型族与代码线索 | 数学对象和输入契约 | 优先求解路线 | 独立验收 |
|---|---|---|---|
| AHP、多层评价 A101–108 | 正互反判断矩阵、层次无环、局部权重对应父节点 | 取主特征根，逐层检查再合成权重 | 互反性、权重非负且和为1、CI/CR；n≤2时CR不适用 |
| 模糊评价/聚类 A120–130 | 隶属度属于[0,1]，边界规则与合成算子明确 | 加权和或 max-min 按语义选择；闭包迭代至不动点 | 分段连接点、概率型行归一、聚类阈值稳定性 |
| LP/MILP、指派 A238–246 | cᵀx、Ax≤b、等式、上下界、整数域逐项对应题意 | 线性结构交求解器；小例枚举核对 | 独立算目标、约束残差、整数性、状态与上下界 |
| 目标/非线性规划 A131–133、253–255 | 可行域、理想点、尺度与偏好 | 先单目标理想值；约束法或可解释权重；光滑连续时局部优化 | 理想点未必共同可行；多起点、边界、梯度/残差核验 |
| 图论 A134–196 | 显式节点集、方向、权重、容量、缺边标记 | 无权BFS；非负Dijkstra；负权Bellman-Ford/Floyd；DAG拓扑递推 | 不可达、零权/负权、孤立点、负环、路径重算 |
| 最大流/费用流 A146、174、189–191 | 有向容量与费用分离；源汇及每个中间点守恒 | 增广路含反向残量；有下界时先做可行流转换 | 容量、守恒、最大流=最小割；费用由原边重算 |
| 覆盖/匹配/染色/旅行商 A137–159、165–173 | 区分点覆盖、边覆盖、独立集；TSP是全点单回路 | 二分图匹配利用专门结构；一般图0-1规划；TSP消子回路 | 极大匹配≠最大匹配；生成树≠最短路径树；度约束不排除子回路 |
| 灰色系统 A197–203 | 正短序列、等间隔、累加/还原关系及预测变量 | GM(1,1)作为候选；关联度与预测分开 | 级比/趋势诊断，a≈0极限，滚动预测；后验比使用同量纲标准差 |
| 回归/PCR A247、256–261 | 样本行、特征列、目标定义、训练划分和秩 | 最小二乘/正则化基线，训练内标准化和降维 | 留出误差、共线性、残差；逆标准化回物理单位 |
| 聚类 A248–250、283/297 | 聚类样本还是指标；尺度和距离 | k-means/层次聚类；多初始化，距离与评价保持一致 | 真实零相关不能删除；轮廓系数和重采样稳定性；簇不是已知类别 |
| 插值 A241–244 | 有序节点、网格或散点、重复坐标、定义域 | 线性/保形基线；光滑需求再用样条 | 节点重现、边界、过冲；不以插值点误差当预测误差 |
| 平滑/趋势 A262–274 | 当前t与下一期t+1分开；warmup、季节长度 | 朴素/移动平均/指数平滑后比较趋势或ARIMA | 同预测原点与步长；训练中选参数；检查误差实际被累计 |
| SA/GA/PSO A204–237、276、286–290 | 编码可行性、目标方向、随机源和预算 | 精确小例→简单邻域基线→必要时启发式 | 当前解/历史最好分离，重算最终适应度，多种子同预算比较 |
| 神经网络/小波 A251–252、275、277–285、289–299 | 样本与通道方向、标签映射、训练内预处理 | 先线性/树基线；少样本时控制容量 | 训练拟合不等于泛化；混淆矩阵按显式标签；工具箱和数据依赖 |

## 可以保留的设计

A105/A108 的层间矩阵乘法展示了评价结果如何在层次间传播；A132 展示先求各目标理想值再做目标达到；A146–154 将图问题写成关联矩阵与整数约束，适合摆脱陈旧工具箱接口。A155 的工程关键路径需要DAG前提。A247 的主成分回归体现了回归系数从标准化空间恢复到物理单位。A265 的移动平均输出与下一期观测对齐方式值得保留。A276/A290 的历史最好解与当前解分离，能防止退火最后一次接受较差解后丢失已有成果。A278/A292 用新生成的噪声样本评价字符识别抗噪性，但它只检验同一字模的噪声稳健性，不检验未见字体泛化。

| A103 | 示例判断矩阵不互反，直接取第一个特征向量未保证为主根 | 构造已知w的aᵢⱼ=wᵢ/wⱼ；扰坏一个互反元素应拒绝 |
| A122 | 第3指标低端平台分支没有赋值 | 核对5.5附近左右值，不能让初始化0替代应有的1 |
| A125 | 固定有限次合成后用早一轮矩阵分组 | 验证 max-min 闭包到不动点；保留阈值定义 |
| A173/A179 | 循环索引写成常量；不可达路径循环缺少退出 | 空图/断开图加预算与不可达状态，不能等挂起再处理 |
| A190 | 反向边用负节点编号，回溯却直接拿负数下标访问 | 6节点反向增广例应得到最大流2；用父节点和边方向独立存储 |
| A196 | Floyd 仅松弛正距离，负边被跳过 | 原C++已运行：1→2=4、2→3=-3、1→3=5，实际5，正确1；缺边不可与零权混同 |
| A201 | 小误差阈值使用方差而非标准差，单位不匹配 | y换计量单位时判断不应因平方缩放而改变；核对残差中心化 |
| A205/A211 | 返回当前解；降温预算可能只随接受次数增加 | 保存best-so-far，按提案数/时限终止 |
| A220 | 末代pop更新后仍用旧popDist选索引 | 个体/适应度同一版本；最终路线重新计算距离 |
| A236/A240 | round生成整数存在端点偏差；随机搜索被放在整数规划目录 | 采样机制直接按分布定义；随机候选最好值不等于整数规划证明 |
| A246 | 两个列向量相乘c*x维度不合 | 目标使用cᵀx；对照手算 |
| A247 | sign(sum(PC))可能把零和特征向量整列清零 | [1,-1]/√2是合法方向；可不定向，或按最大绝对载荷定向 |
| A248/A250 | nonzeros去掉合法零相关，破坏距离向量索引 | 显式三角索引；保留零并核对凝聚向量长度 |
| A262/A268 | 下一期预测画在本期；空误差列表追加自身而非新误差 | 明确预测时间戳，验证误差数量与回测原点一致 |
| A270–274 | 参数与函数使用的变量名不一致，依赖未定义变量 | 独立进程运行，函数显式传参，不依靠工作区遗留量 |
| A275/A289 | 所谓动量只是当前梯度乘常数；整条曲线当一个输入向量 | 真动量保存历史增量；区分曲线记忆与未见x泛化 |
| A280/A294 | 划分前归一化，混淆矩阵正确类别标签交换 | 训练内拟合缩放，真实行/预测列用显式标签建立矩阵 |

以上具体风险适用于台账中的固定版本，不能外推为这些数学算法本身错误。静态问题尚未用原 MATLAB 环境逐一执行。

## MATLAB / Python迁移

先迁移数学接口，再替换函数名。MATLAB通常从1计数、按列展平，NumPy从0计数、默认按行；重塑指派矩阵时用一个带行列标签的小例核对。MATLAB的矩阵乘`*`与逐元素`.*`在NumPy中分别对应`@`与`*`。方差/标准差自由度要显式统一，随机种子相同也不保证跨语言随机序列相同。

把`clear/clc/uicontrol/pause`等演示层与计算函数分开，所有输入文件、工具箱、求解器、编码和函数路径显式列出。`newff/newsom/dividevec/miqp`等历史接口不要只机械改名；按当前环境可调用接口重建同一数学对象，做数值对照后记录差异。无 MATLAB/Octave 时标“静态审阅”或“独立语义重实现”，不能写“原程序运行通过”。

随机算法保留预算、种子和中间最好值；检查最终解与最终目标配对。精确求解器检查success/status之外，还检查primal可行性；整数解不能随意四舍五入。大型稀疏图避免全对距离表，局部查询按需计算/缓存。组合搜索不在训练集之外偷看真实答案来定参数。
