# 数学建模

把实际问题转成可计算、可检验、能回答题目要求的模型。默认以本科国赛和美赛的复杂度组织工作，使用用户指定的软件和语言；未指定时按现有环境选择 Python、MATLAB 或其他适合的工具。

依据用户的实际阶段开展工作，不强迫已有成果从头重做。

## 从题目到模型

1. **锁定题目契约。** 保留题面原编号，并覆盖其下子任务和未编号的实质要求；提取数值、解释、方案、图表和附件格式；区分硬约束、可权衡目标和自行增加的假设。列出各问依赖，优先处理决定后续结果的参数和数据。关键歧义先比较会改变结论的解释，用边界或数量级验算说明采用依据；新增条件未改变结果时检查约束是否活跃，不倒推修改题意。题目未定义“最好”时明确目标含义，不擅自把成本、精度、舒适度等合成一个无来源分数。
2. **先验证数据能支撑什么。** 核查记录粒度、单位、时间范围、主键、缺失与真实零、重复、异常、标签和决策时可用的信息。预测任务先确定时间或分组划分，再在训练部分拟合插补、标准化、降维和调参。缺少原始数据时给出参数化模型、待验证项和最小数据需求；示例数据与真实结论分开。
3. **先得到可信基线。** 用简单模型贯通一问的数据、求解、验证和输出。再根据基线的具体缺陷引入结构或算法，写清增加它解决了什么。不要把 AHP、熵权、TOPSIS、预测和启发式优化机械串联；不要把参考论文的算法名称当成选型理由。
4. **表达完整数学对象。** 定义变量、参数、单位、目标、约束、状态转移或方程及定解条件。模型描述现实中的可行集合；贪心规则、编码方式、搜索步长属于求解方法，不能混成物理约束。先考虑可线性化、可分解、可利用单调性或图结构的部分，再决定是否需要通用黑箱优化。
5. **留下求解证据。** 保存数据来源/哈希、预处理、模型版本、参数、随机种子、运行命令、依赖版本、停止状态和结果文件。区分理论最优、求解器已证明最优、给定容差内的解、当前最好可行解、仿真估计。调用了求解器不等于取得可行解，收敛曲线变平不等于全局最优。

## 决定答案能否采用

验证围绕影响答案的风险展开，至少覆盖该题的关键约束与一个合理基线，避免为了凑章节做无关检验。

- **可行性先于性能。** 由结果独立重算资源占用、守恒、容量、工序、时间窗、边界条件和题目硬约束。不能因平均指标好看而忽略局部违规。调度问题可用 [事件检查器说明](references/schedule-checker.md)，但仍需补充具体设备的运动与工艺检查。
- **数据检验不能自证。** 拟合误差、留出预测误差、数值离散误差、仿真不确定性是不同证据。避免用建立规则的同一批数据证明规则泛化，或用同一个行为假设生成的结果宣称策略在现实中已有效。
- **比较口径一致。** 统一数据、预算、约束、信息可见性、评价期、随机场景与计算资源。分别报告实际观测和模型预计；百分比的相对变化与百分点变化分开。
- **敏感性要能改变决策。** 扰动关键参数、权重、缺失处理或分布假设，说明推荐方案、排名、可行性和误差是否变化。时间序列使用滚动回测；随机仿真报告多次独立运行的分布与不确定性；微分方程检查网格/步长收敛及物理量守恒。
- **公式、代码、表格相互核对。** 尤其检查 `min/max`、正负号、转置、概率归一化、量纲、目标方向与索引。历史优秀论文也可能存在错误，见案例 C1–C4、C7、C10–C15。原始代码与数学算法分别审查；用负边、退化矩阵、断开图、边界和小规模精确解检验实现，区分静态审阅、独立重实现和原环境执行。

## 输出与论证

根据用户要求交付分析、可运行代码、结果文件或论文，不自动扩张为全部文档。每问先给结论，再说明模型、参数来源、求解和检验；关键数值应能追溯至结果文件。跨阶段交接记录实际实现、结果版本和待验证项；上游数据或模型变动后使相关下游结果失效并更新。论文按论证逻辑组织，摘要在结果稳定后写，结论只使用已经获得的证据。

结果未验证时明确写“模型预计”“待计算”或“尚未复现”，不编造精度、获奖等级、引用或实验。只做润色时不擅自更换模型和数值；发现实质错误，说明受影响的结论并优先修复。

交付排版后的论文/PDF 时，构建或导出与视觉检查均应真实执行；关键项未运行就标为未完成，不宣称可提交。自动脚本通过不等于模型、正文语义和赛事规则均通过。结果多或反复改稿时用 [证据检查器](references/evidence-checker.md) 核对声明的文件哈希和结果字段。

## 历史资料的使用边界

本技能由两个资源仓库的结构整理、本科论文重点章节研读及评阅材料对照形成，不是所有论文的全文结论库。后续参考 MathModelAgent 的阶段工作流，独立改写交接、编程、图表和验收规则；[借鉴范围与修正](references/workflow-source-review.md) 保留固定来源，不将上游的经验阈值或模板约定当作定理/赛事规定。阅读范围和固定提交见 [来源地图](references/source-map.md) 与 `references/sources.json`。

- 按题目正文确认赛事。`zhanwen/MathModel` 的“国赛论文”“国赛试题”含大量研究生竞赛资料，不直接作为本科国赛标签。
- 按内容确认方法。一篇论文可能跨模型目录重复出现；“动态规划”目录中的论文也可能以其他方法为主。先用 Git blob SHA 去重，再阅读。
- 赛题、评阅提示、参赛论文、经验贴、示例代码的证据等级不同。转载评阅材料不是当前赛事的规则文件，开放题也未必存在唯一答案。
- 学习可迁移的结构并注明来源，不复制整篇论文或套用历史数值。模板中的预填成绩、模拟ROC/SHAP与人工调参曲面只能作为外观示例，正式图表必须绑定真实数据、模型及运行记录。涉及当前比赛格式、页数、AI 使用和提交要求时核对该届官方文件；不把旧模板和经验贴中的时间安排固化为规定。

检索示例（路径相对于本技能目录）：

```bash
python3 scripts/catalog.py search --query "2018 A229" --scope undergraduate
python3 scripts/catalog.py search --query "Topsis" --kind paper --unique
python3 scripts/catalog.py source P08
```
