# 数学建模技能的资料整理与研究报告

本次任务的目标是将两个资源仓库转成本科生可复用的建模工作方法。成果包括 `math-modeling` 技能、案例分析、固定版本来源索引，以及两个可运行的辅助脚本。

## 1．资料范围与整理结果

仓库来源为 [zhanwen/MathModel](https://github.com/zhanwen/MathModel) 与 [personqianduixue/Math_Model](https://github.com/personqianduixue/Math_Model)。2026-09-10 获取完整递归文件树，分别为 1,955 与 7,938 个文件条目，文件标称字节合计约 10.41 GB；未下载全部文件。

合并 9,893 条记录后有 7,724 个不同 Git blob，2,169 条是相对于首次出现的重复路径记录。两仓库共同持有 1,013 个相同 blob。这是字节级去重；水印、扫描版、改名后重新编码的同一论文可能仍重复。

整理发现：

- 第一个仓库广泛收录研赛论文、题目、模板、算法和美赛论文，“国赛论文”这个目录名不能直接理解为本科国赛。
- 第二个仓库明确分出本科/专科国赛、研赛、美赛，以及按模型分类的论文和评阅材料，适合本科优先路由。
- 模型分类有交叉和误导。例如 P19 放在动态规划目录，但主体采用 EMSR 与收益机会评价；一篇能源论文可以同时出现在时间序列、评价等目录中。
- 示例程序与参考书具有不同使用成本；不能因为 `.m` 文件存在就假设环境兼容或结果正确。

因此保留原路径和固定提交，增加保守的赛事集合、文件类型和已研读来源标识。只将确定的标题写入已验证标题字段；其余标签明确标记为路径推断。完整统计见 [inventory-summary.json](../math-modeling/references/inventory-summary.json)。

## 2．抽样与阅读方法

为本科主线选择四组同题双论文：2017 A（CT）、2017 B（定价）、2018 A（传热）、2018 B（RGV）。再选择六篇美赛论文，覆盖登机、灌溉、能源评价预测、超售和收费站，共 14 篇、9 个题目。

两篇同题对照比单篇模仿更有价值：它暴露相同题目下不同假设、目标和验证方式，也能发现“结果不同”不是简单数值误差，而是模型条件不同。

对核心样本阅读摘要与模型、求解、检验、局限等重点页，配对 4 份赛题和 7 份评阅文件。关键公式/表格额外渲染并查看 8 个 PDF 页面，避免把抽取遗漏当成原文错误。记录每个来源的仓库、提交、blob SHA、下载校验哈希、PDF 文件页及阅读状态。

本次不是全库逐篇全文精读：大批题库、书籍、课件、压缩包只建立目录。扫描文本层不足的候选 P09/P10 未进入核心案例；研赛候选按用户指定的本科范围排除。没有执行历史论文的完整代码，也没有重新生成其全部附件结果。各篇范围见 [来源地图](../math-modeling/references/source-map.md)。

## 3．优秀论文中可迁移的能力

### 将复杂任务拆成有依赖的数学对象

CT 把参数标定放在重建之前；传热把状态预测放在厚度优化之前；定价区分历史价格、接受行为和受容量限制的分配；能源题区分评价、预测和目标设置。这种拆分让前一问输出成为下一问输入，并使误差传播可讨论。

技能因此要求先明确每问交付物、变量、参数及依赖，而不是首先列算法清单。复杂模型只在基线暴露具体缺陷时引入。

### 用问题结构降低求解难度

小圆投影不变性帮助标定；网络流把接受关系与会员限额连接；事件时刻避免逐秒重复计算；空间网格让局部灌溉水量可检查。模型的关键在于保留决定答案的结构。

其中也可以改进原文：P01 的余弦参数关系通过变量代换成为线性最小二乘，不必由“非线性”直接跳到智能搜索。本项目用合成数据验证了这项独立推导；这不等于复现原题数据。

### 让验证与输出一致

历史评阅材料共同关注可计算的模型、与题目相关的检验、程序与论文的一致性。RGV 的最终证据是可行事件表，CT 是标定和重建的量化误差，定价是预算和行为条件明确的预计效果。

因此技能区分四类证据：拟合残差、样本外误差、数值离散误差、随机仿真误差。任何一种都不能自动替代其他证据。平均性能好不豁免硬约束，光滑曲线不保证外推正确。

### 论文是论证，不是过程记录

登机论文从机制分析走到可执行建议；能源论文把多维指标转成决策输出。值得借鉴的是解释每个模型模块为何存在、数字支持什么选择、什么条件下结论失效。

技能写作部分由结果证据台账驱动，要求每问直接给答案与验证。摘要最后写，且不能补造尚未得到的精度、提升或最优性。

| 来源 | 收录版本中观察到的问题 | 技能中的修正 |
| --- | --- | --- |
| P01，第 19 页 | 将非线性超定关系导向智能搜索，未利用余弦的线性代换 | 检查可线性化结构、秩与可辨识性，再选求解器 |
| P04，第 12 页 | 完成率 62.1%→86.6%，文中写提高 24.5%；成本也变化 | 分开百分点、相对变化；统一预算再比较策略 |

| P08，第 7/16 页 | 瓶颈描述与 max 公式不一致；差距定义与表中达成比例不一致 | 分开模型、界与比率的数学定义，并从表中重算 |

这些发现不等于否定论文所有价值，也不用于重新评奖。技能保留有用的建模抽象，同时要求复核容易被优秀标签掩盖的局部错误。

## 5．技能结构与使用方式

入口 [SKILL.md](../math-modeling/SKILL.md) 保持集中，按用户阶段路由：新题读模型选择，求解读验证，写作读论文组织，复盘读案例，查资料读来源地图。较长的案例与目录不在每次调用时全量加载。

两个脚本分别提供：

- `catalog.py`：离线元数据检索、固定版本原件链接、按 blob 合并命中项，以及来源阅读记录查询。
- `check_schedule.py`：对声明的独占资源、事件区间、工序关系、最低时长、释放/截止时刻和停机日历独立验证。

检查器采用通用事件契约而非直接复制某篇 RGV 代码。针对具体题目仍需补运动、物料、清洗、故障与完成件计数等限制，输出通过不能当作完整最优性证明。

## 6．质量结论与限制

交付时验证技能结构、内部引用、完整目录统计及 35 条来源与固定 tree 的一致性；运行 20 项脚本测试，以及合成参数辨识和三项局部数学/数值复核。详见 [验证报告](validation-report.md)。

本技能的定位是增强本科建模中的决策与校验能力。它不是论文全文库、获奖保证或自动套题器；所有真实赛题结果仍应由当前输入、模型和程序生成。需要当前赛事格式或规则时，使用当届官方文件。
