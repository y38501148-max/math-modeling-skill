## 对具体论文的局部复核

1. **P01 余弦结构。** 用 6 个合成角度和已知 `r=5, φ=0.3, C=2` 构造观测，以 `[cosθ,sinθ,1]` 线性最小二乘恢复参数；设计矩阵满秩，最大残差小于 `10^-12`。这是对独立数学改写的验证，不是对原论文 CT 附件的复现。
2. **P04 百分比。** 重算 `57641.5→58732.6` 为约增 `1.8929%`，`62.1%→86.6%` 为增 `24.5` 个百分点，相对约增 `39.4525%`。
3. **P08 达成比例与差距。** `382/384≈0.9947917`，`(384-382)/384≈0.0052083`；两者语义相反，不能用同一名称。
4. **P05 阈值时间。** 对表中 3322 秒/43.99977℃ 与 3323 秒/44.00008℃ 线性插值，越界约为 3322.742 秒。在后续单调且持续高于阈值至 3600 秒的条件下，时长约 277.258 秒；完整时间序列仍须复算，未把该局部插值当作原题完整答案。
